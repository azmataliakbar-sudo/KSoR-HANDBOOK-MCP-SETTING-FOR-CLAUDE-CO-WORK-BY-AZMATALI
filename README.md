# KSoR Handbook2 MCP

## Quick Setup (2 minutes)

1. Go to [claude.ai/settings/customize-connectors](https://claude.ai/new?modal=add-custom-connector#settings/customize-connectors)
2. Add custom connector:
   - Name: `KSoR Handbook2`
   - URL: `https://ksor-handbook2-git-master-azmat-alis-projects-eb08bc9e.vercel.app/mcp`
   - Auth: No sign-in
   - Header: `Authorization: Bearer disabled-public`
3. Click "Add" → Done!

- 🔍 Search handbook
- 📖 Read documents
- 📋 Outline records
